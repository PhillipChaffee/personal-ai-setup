# Pivot: herdr-based coding agents and a wizard front door; automations dropped

2026-09-19. The repo's code-agent plane — one OpenCode container per chat, managed by `code-agent-manager` — is replaced by herdr (github.com/herdrdev/herdr) on the same Hetzner brain: real terminal panes, the herdr server owns state, clients attach over SSH/Tailscale. Setup is rebuilt around a single wizard script as the front door (generated with the `wizard` skill) that reuses the existing unit engine and lets the person setting up choose the coding agents (OpenCode + Pi first-class; Claude Code, Codex, Gemini CLI in the catalog). All shipped automations are dropped — the user finds scheduled recipes annoying and wants none, so `goose serve` runs without the scheduler and no recipes/timers ship.

Considered: keeping the container plane (rejected — herdr's terminal model is simpler and already in daily use on the Mac); Goose's own ACP-provider orchestration of coding agents (rejected — herdr owns that role); Raccoon Herder (rejected — pre-release, no public install). The Sep-12 herdr-on-brain epic design was agreed but never built; it is the base for the new plane, revised by this pivot.
